## 2. 검토 사항

### R-1 표시 정보 검수 폐지로 남은 책임

본사 검수 절차를 없앴다. 알레르기와 원산지 표시의 정확성이 매장 책임으로 넘어갔다.

시스템은 필수 항목 누락만 막는다. 값이 사실인지는 확인하지 않는다. 매장이 원산지를 잘못 적어도 걸러지지 않는다.

**[확인 필요]** 가맹 계약서에 표시 책임을 명시해야 한다. 표시 위반 과태료가 매장에만 부과되는지 플랫폼에도 미치는지 법무 확인이 필요하다.

### R-2 연계 규격이 문서에 없다

07 기능 명세를 화면 단위로 작성했다. 목적, 대상, 처리, 조건, 예외, 연결 Flow를 갖췄다.

외부 연계 규격은 아직 없다. 결제대행사와 VAN사, 알림톡, 외부 POS의 요청과 응답 항목이 정의되지 않았다. 계약 후 상대가 제공하는 규격에 맞춰야 하므로 지금 확정할 수 없다. 계약 시 확인할 항목은 02 문서 2.7과 2.22에 있다.

### R-3 확정된 결정이 미결로 표기되어 있었다

02 문서의 DC-001부터 DC-004까지가 상태 미결로 남아 있었다. 네 건 모두 이미 적용 기준과 Flow에 반영되어 있고 문서 전체가 그 결정을 전제로 쓰였다.

미결 표기는 이슈 목록에도 등록되어 있지 않았다. 상황판의 미결 건수와 문서의 표기가 서로 달랐다.

네 건을 확정으로 정리했다. DC-001은 계약 체결 전 법무 검토를 조건으로 단다.

| 결정 | 확정 내용 |
| --- | --- |
| DC-001 결제·정산 계약 구조 | 외부 결제대행사가 정산을 전담한다. 플랫폼은 대금을 수취하지 않는다 |
| DC-002 메뉴 기준의 위치 | 매장이 등록한 메뉴가 유일한 기준이다. 외부 POS는 조회만 한다 |
| DC-003 메뉴 변경의 반영 시점 | 저장과 반영을 분리하지 않는다. 채널별 확인 시점만 다르게 둔다 |
| DC-004 주문 접수 화면의 위치 | 가맹 어드민 안에 둔다. 매장 전용 화면을 만들지 않는다 |
