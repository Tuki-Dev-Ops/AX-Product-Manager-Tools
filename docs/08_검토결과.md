# 08. 검토 결과

검토일 2026-09-08. 01부터 07까지를 대상으로 한다.

조치가 끝난 항목은 이 문서에 남기지 않는다. 처리 이력은 `_data/changes.yaml`에 있다. 아래는 현재 시점에 열려 있는 검토 내용만 적는다.

## 1. 현재 상태

| 구분 | 건수 |
| --- | --- |
| 요구사항 | 48 |
| 비기능 요구사항 | 56 |
| 의사결정 | 16 |
| 기능 | 65 |
| 화면 | 87 |
| Wireframe | 167 |
| 기능 명세 | 87 |
| Flow | 103 |

화면 87건이 모두 어느 Flow에든 나오고 화면마다 기능 명세가 있다. 요구사항에서 기능, 기능에서 화면과 Flow로 이어지는 경로에 끊긴 곳이 없다.

Wireframe 167건은 화면 87건의 기본 상태와 상태별 변형을 합한 수다. 목록의 결과 없음, 등록·수정의 검증 오류, 처리 결과 안내가 모두 포함된다.

## 2. 검토 사항

### R-1 표시 정보 검수 폐지로 남은 책임

본사 검수 절차를 없앴다. 알레르기와 원산지 표시의 정확성이 매장 책임으로 넘어갔다.

시스템은 필수 항목 누락만 막는다. 값이 사실인지는 확인하지 않는다. 매장이 원산지를 잘못 적어도 걸러지지 않는다.

**[확인 필요]** 가맹 계약서에 표시 책임을 명시해야 한다. 표시 위반 과태료가 매장에만 부과되는지 플랫폼에도 미치는지 법무 확인이 필요하다.

### R-2 연계 규격이 문서에 없다

07 기능 명세를 화면 단위로 작성했다. 목적, 대상, 처리, 조건, 예외, 연결 Flow를 갖췄다.

외부 연계 규격은 아직 없다. 결제대행사와 VAN사, 알림톡, 외부 POS의 요청과 응답 항목이 정의되지 않았다. 계약 후 상대가 제공하는 규격에 맞춰야 하므로 지금 확정할 수 없다. 계약 시 확인할 항목은 02 문서 2.7과 2.22에 있다.

### R-3 매장 관리를 상권 아래로 옮긴 뒤 남은 확인 사항

매장 목록을 없애고 상권 상세의 매장 탭에서 매장을 관리하도록 바꿨다. 매장은 상권 하나에 속하므로 동선은 맞다.

다만 상권을 가로질러 매장을 찾는 경로가 사라졌다. 사업자번호나 매장명만 알고 어느 상권인지 모르는 경우 지금 구조에서는 상권을 하나씩 열어봐야 한다.

**[확인 필요]** 운영 중 매장을 상권과 무관하게 찾는 일이 얼마나 있는지 확인이 필요하다. 잦다면 대시보드에 매장 검색을 두거나 매출 조회의 매장 조건을 검색으로 바꾼다.

### R-4 계정 발급 경로가 둘이다

상권을 등록하면서 담당 계정을 함께 발급한다. 시스템 > 관리자에서도 계정을 발급한다.

두 경로가 만드는 계정은 같다. 상권 등록에서는 역할이 가맹 관리자, 담당 범위가 그 상권으로 고정되고, 관리자 메뉴에서는 둘 다 고를 수 있다.

계정 정보 수정과 비밀번호 재설정, 사용 중지는 관리자 메뉴에서만 한다. 상권 화면에서는 읽기만 한다. 발급 경로는 둘이지만 관리 경로는 하나다.

**[가정]** 상권 담당자가 여러 명인 경우는 관리자 메뉴에서 계정을 추가한다. 상권 등록에서 계정을 여러 개 만드는 화면은 두지 않는다.

## 3. 확인한 것

아래는 검토 결과 문제가 없었다.

| 항목 | 결과 |
| --- | --- |
| 추적성 | 요구사항부터 화면까지 끊긴 곳이 없다 |
| 기능과 Flow 일치 | 기능이 모두 어느 Flow에든 나온다 |
| 화면과 Flow 일치 | 화면 87건이 모두 어느 Flow에든 나온다 |
| 화면과 명세 일치 | 화면 87건에 기능 명세가 모두 있다 |
| 식별자 | 중복과 재사용이 없다. 삭제한 항목의 번호를 다시 쓰지 않는다 |
| 화면 상태 | 목록의 결과 없음, 등록·수정의 검증 오류, 처리 결과 안내가 모든 해당 화면에 있다 |
| 입력 요소 | 상태가 바뀌어도 드롭다운, 날짜, 검색 입력의 종류 표시가 유지된다 |
| 예외 처리 | 결제 유실, 금액 불일치, 미접수, 망취소, 네트워크 단절, 로그인 실패 여섯 가지를 별도 Flow로 둔다 |
| 권한 경계 | 본사와 매장이 다루는 대상이 겹치지 않는다 |
| 기준 데이터 | 각 데이터의 원본 도메인이 정해져 있다 |
| 법정 표시 | 알레르기, 영양성분, 원산지의 대상 판정과 화면 표시 기준이 법령 근거와 함께 있다 |
| 규제 | 결제와 정산 구조가 등록 의무를 피하는 근거와 함께 정해져 있다 |
| 접근성 | 키오스크 기술 기준 16개 항목이 01 문서 8.7에 있다 |
