# 08. 검토 결과

검토일 2026-09-08. 01부터 07까지를 대상으로 한다.

조치가 끝난 항목은 이 문서에 남기지 않는다. 처리 이력은 `_data/changes.yaml`에 있다. 아래는 현재 시점에 열려 있는 검토 내용만 적는다.

## 1. 현재 상태

| 구분 | 건수 |
| --- | --- |
| 요구사항 | 46 |
| 비기능 요구사항 | 56 |
| 의사결정 | 16 |
| 기능 | 63 |
| 화면 | 81 |
| Wireframe | 161 |
| 기능 명세 | 81 |
| Flow | 97 |

화면 81건이 모두 어느 Flow에든 나오고 화면마다 기능 명세가 있다. 요구사항에서 기능, 기능에서 화면과 Flow로 이어지는 경로에 끊긴 곳이 없다.

Wireframe 161건은 화면 81건의 기본 상태와 상태별 변형을 합한 수다. 목록의 결과 없음, 등록·수정의 검증 오류, 처리 결과 안내가 모두 포함된다.

## 2. 검토 사항

### R-1 연계 규격이 문서에 없다

07 기능 명세를 화면 단위로 작성했다. 목적, 대상, 처리, 조건, 예외, 연결 Flow를 갖췄다.

외부 연계 규격은 아직 없다. 결제대행사와 VAN사, 알림톡, 외부 POS의 요청과 응답 항목이 정의되지 않았다. 계약 후 상대가 제공하는 규격에 맞춰야 하므로 지금 확정할 수 없다. 계약 시 확인할 항목은 02 문서 2.7과 2.22에 있다.

### R-2 계정 발급 경로가 둘이다

상권을 등록하면서 담당 계정을 함께 발급한다. 시스템 > 관리자에서도 계정을 발급한다.

두 경로가 만드는 계정은 같다. 상권 등록에서는 역할이 가맹 관리자, 담당 범위가 그 상권으로 고정되고, 관리자 메뉴에서는 둘 다 고를 수 있다.

계정 정보 수정과 비밀번호 재설정, 사용 중지는 관리자 메뉴에서만 한다. 상권 화면에서는 읽기만 한다. 발급 경로는 둘이지만 관리 경로는 하나다.

**[가정]** 상권 담당자가 여러 명인 경우는 관리자 메뉴에서 계정을 추가한다. 상권 등록에서 계정을 여러 개 만드는 화면은 두지 않는다.

## 3. 확인한 것

아래는 검토 결과 문제가 없었다.

| 항목 | 결과 |
| --- | --- |
| 추적성 | 요구사항부터 화면까지 끊긴 곳이 없다 |
| 기능과 Flow 일치 | 기능이 모두 어느 Flow에든 나온다 |
| 화면과 Flow 일치 | 화면 81건이 모두 어느 Flow에든 나온다 |
| 화면과 명세 일치 | 화면 81건에 기능 명세가 모두 있다 |
| 연결 점검 | 요구사항, 기능, Flow, 화면, 명세 사이에 끊긴 연결이 없다. 점검 결과 0건 |
| 비기능 요구사항 | 56건 모두 판정 기준과 근거를 갖췄다. trace.yaml에 등록해 점검 대상에 넣었다 |
| 명세 구성 | 화면 81건의 명세가 목적, 대상, 유형, 연결 Flow, 처리, 조건, 예외를 갖췄다 |
| 조사 근거 | 조사 원본 16건이 모두 본문에서 참조된다 |
| 식별자 | 중복과 재사용이 없다. 삭제한 항목의 번호를 다시 쓰지 않는다 |
| 화면 상태 | 목록의 결과 없음, 등록·수정의 검증 오류, 처리 결과 안내가 모든 해당 화면에 있다 |
| 입력 요소 | 상태가 바뀌어도 드롭다운, 날짜, 검색 입력의 종류 표시가 유지된다 |
| 예외 처리 | 결제 유실, 금액 불일치, 미접수, 망취소, 네트워크 단절, 로그인 실패 여섯 가지를 별도 Flow로 둔다 |
| 권한 경계 | 본사와 매장이 다루는 대상이 겹치지 않는다. 본사는 기준정보 등록과 계정 발급, 매장은 운영을 맡는다 |
| 화면 표기 기준 | 필수·선택 표기, 강조 버튼 수, 표 정렬, 오류 문구를 KRDS 기준으로 맞췄다. 한 화면에 두 표기를 섞은 곳 0건 |
| 표 데이터 | 금액의 천 단위 구분과 셀 구분이 섞여 열이 밀린 행 11건을 고쳤다. 머리글과 본문의 칸 수가 모두 맞는다 |
| 조작 영역 | 키오스크와 모바일 화면의 버튼, 입력 칸, 탭, 표 행을 44px 이상으로 둔다 |
| 입력 라벨 | 모든 입력 칸에 라벨이 있다. 안내 문구만 두고 라벨이 없던 웹앱·키오스크 6곳을 보완했다 |
| 명세 구성 중복 | 조건과 예외에 같은 문장을 겹쳐 적은 화면 13건을 정리했다 |
| 변경 추적 | 본사와 매장이 바꾼 값을 모두 이력에 남기고 상권 상세의 히스토리 탭에서 본다 |
| 기준 데이터 | 각 데이터의 원본 도메인이 정해져 있다 |
| 법정 표시 | 알레르기, 영양성분, 원산지의 대상 판정과 화면 표시 기준이 법령 근거와 함께 있다 |

| 매장 조회 경로 | 상권을 모르는 상태에서 매장을 찾는 경로를 매출 조회 하나로 정했다 |
