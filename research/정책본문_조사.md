# 정책 본문 작성 기준 조사

조사일 2026-09-09. 이용약관, 개인정보 처리방침, 알림톡 템플릿의 작성 기준을 확인했다.
갖춰야 할 정책의 목록은 `research/필수정책_조사.md`에 있다. 이 문서는 그 안에 무엇을 어떤 순서로 담을지 다룬다.

## 1. 플랫폼의 법적 지위

먼저 정리해야 할 것이 있다. 아이오더가 통신판매업자인지 통신판매중개자인지다.

음식을 팔고 대금을 받는 것은 매장이다. 아이오더는 주문을 받아 매장에 전달하는 수단을 제공한다.
결제는 결제대행사가 처리하고 아이오더는 대금을 수취하지 않는다.
따라서 아이오더는 **통신판매중개자**이고 매장이 **통신판매중개의뢰자**다.

### 중개자에게 붙는 의무

| 조문 | 의무 |
| --- | --- |
| 전자상거래법 제20조 제1항 | 자신이 거래 당사자가 아니라는 사실을 미리 고지한다 |
| 제20조 제2항 | 중개의뢰자의 정보를 소비자에게 제공하거나 열람할 방법을 제공한다 |
| 제20조의2 제1항·제2항 | 위 둘을 하지 않았거나 제공한 정보가 사실과 다르면 중개의뢰자와 연대해 배상한다 |
| 제20조의2 제3항 | 불만이나 분쟁이 생기면 원인과 피해를 파악하는 등 필요한 조치를 신속히 시행한다 |

제20조의2 제3항이 중요하다. **분쟁 처리는 선택이 아니라 의무다.**
매장 연락처만 안내하고 손을 떼는 것은 이 조항에 어긋난다.

2026년 10월 22일부터 통신판매중개사업자에게 입점 사업자 대상 원산지 표시제도 고지 의무가 생긴다.
아이오더는 중개자이므로 이 의무의 대상이다.

## 2. 이용약관

공정거래위원회가 「전자상거래(인터넷사이버몰) 표준약관」을 두고 있다. 이를 바탕으로 하되
본 서비스에 없는 조항(배송, 회원 가입, 포인트)은 빼고 픽업 주문에 맞춘다.

### 담을 조항

| 조 | 내용 |
| --- | --- |
| 목적과 용어 | 아이오더, 매장, 고객, 주문의 뜻을 정한다 |
| 서비스의 성격 | 아이오더는 중개자이고 매장이 판매자임을 밝힌다 |
| 주문의 성립 | 매장이 접수한 때 성립한다. 결제 승인만으로는 성립하지 않는다 |
| 취소 | 접수 전과 접수 후 1분까지 고객이 취소한다. 조리 중부터는 취소할 수 없다 |
| 매장의 거절 | 매장이 거절하거나 5분 안에 접수하지 않으면 자동 취소하고 전액 환불한다 |
| 미수령 | 영업 종료 한 시간 뒤 수령 완료로 마감하고 환불하지 않는다 |
| 환불 | 취소가 확정되면 결제수단으로 전액 환불한다. 조리 시작 이후 환불은 매장이 판단한다 |
| 개인정보 | 처리방침에 따른다 |
| 분쟁 | 아이오더가 원인과 피해를 파악하고 필요한 조치를 한다. 관할 법원을 정한다 |
| 약관 변경 | 시행일 7일 전에 알린다. 고객에게 불리한 변경은 30일 전에 알린다 |

미수령을 환불하지 않는 것은 고객에게 불리한 조항이다.
약관에 적는 것만으로는 부족하고 결제 전 화면에도 알려야 효력을 주장할 수 있다.

## 3. 개인정보 처리방침

개인정보보호위원회 「개인정보 처리방침 작성지침」(2025.4.)이 항목과 순서를 정하고 있다.

### 지침이 정한 순서

1. 처리 목적
2. 처리하는 개인정보의 항목
3. 14세 미만 아동의 개인정보 처리
4. 처리 및 보유 기간
5. 파기 절차와 방법
6. 제3자 제공
7. 추가적인 이용·제공의 판단 기준
8. 처리업무의 위탁
9. 국외 수집과 이전
10. 안전성 확보조치
11. 민감정보의 공개 가능성과 비공개 선택 방법
12. 가명정보 처리
13. 자동 수집 장치의 설치·운영과 거부
14. 개인정보 보호책임자와 고충 처리 부서
15. 권리·의무와 행사 방법

해당하지 않는 항목은 적지 않아도 된다. 본 서비스는 3, 7, 9, 11, 12가 해당하지 않는다.
14세 미만 아동을 대상으로 하지 않고, 추가적인 이용·제공을 하지 않으며,
국외로 옮기지 않고, 민감정보와 가명정보를 다루지 않는다.

## 4. 알림톡 템플릿

카카오가 유형과 규격을 정하고 있다.

| 항목 | 규격 |
| --- | --- |
| 유형 | 기본형, 부가정보형, 채널추가형, 복합형 |
| 본문 | 한글·영문 구분 없이 1,000자 |
| 부가정보 | 500자. 변수를 쓸 수 없고 URL은 넣을 수 있다 |
| 강조표기 | 말풍선 위에 중요한 문구를 크게 보인다 |
| 변수 | 40개 이하. 변수만으로 이루어진 템플릿과 변수가 들어간 버튼명은 쓸 수 없다 |
| 버튼 | 웹링크(WL), 채널추가(AC) 등 |

주문 상태를 알리는 문구는 정보성 메시지라 발송할 수 있다.
템플릿을 미리 등록하고 심사를 통과해야 한다.

본 서비스는 **기본형**을 쓴다. 주문번호와 매장명, 상태만 알리면 되고 광고를 붙이지 않는다.
주문 조회 링크는 웹링크 버튼으로 둔다.
