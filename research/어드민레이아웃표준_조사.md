# 어드민 화면 배치 표준 조사

조사일 2026-09-09. 조회 조건 영역과 표 툴바, 액션 버튼 자리를 국내외 디자인 시스템 원문으로 확인했다.
화면마다 갈리던 배치를 하나로 정하는 것이 목적이다.

---

## 1. 조회 조건 영역

### 한 줄에 두는 조건 수

Ant Design은 고급 검색 패턴에서 "한 줄에 입력 칸을 세 열 넘게 두지 말 것"을 권고한다.
조건이 많으면 접어 두고 펼치게 한다.

조건 순서는 표의 열 순서와 맞추고, 자주 쓰는 조건을 위에 둔다.

- Advanced Search (Ant Design) — https://2x.ant.design/docs/pattern/advanced-search

### 조회와 초기화 버튼

두 버튼은 조건 칸 오른쪽 끝에 나란히 둔다. Ant Design Pro의 QueryFilter가 같은 배치를 쓴다.

버튼 순서는 초기화를 왼쪽, 조회를 오른쪽에 둔다.
초기화는 입력한 조건을 지우는 되돌릴 수 없는 동작이라, 주 동작인 조회 오른쪽에 두면 잘못 누르기 쉽다.
순서를 바꾸고 강조를 나눠 위험을 줄인다.

- Query/LightFilter (ProComponents) — https://procomponents.ant.design/en-US/components/query-filter/
- Filter UI Design 정리 — https://www.aufaitux.com/blog/filter-ui-design/

## 2. 표 툴바

Carbon Design System은 표 툴바를 전역 동작 자리로 정의한다.
검색은 표 제목 아래 왼쪽에 두고 오른쪽 액션까지 늘어난다. 액션은 오른쪽에 모은다.

| 항목 | 규칙 |
| --- | --- |
| 툴바 액션 수 | 다섯 개까지. 넘으면 더보기로 접는다 |
| 배치 액션 | 행을 고르면 표 위에 뜬다. 취소는 맨 오른쪽에 둔다 |
| 페이지네이션 | 항상 표 아래에 둔다 |
| 정렬 | 열 머리의 화살표로 표시한다 |
| 제목과 설명 | 표 맨 위에 둔다 |

- Data table usage (Carbon) — https://carbondesignsystem.com/components/data-table/usage/

## 3. 페이지 머리말과 주요 동작

Atlassian은 제목 줄 오른쪽에 동작 버튼을 두고 그 아래에 필터를 왼쪽 정렬로 둔다.
강조 색은 화면당 주 동작 하나에만 쓴다.

목록 화면의 등록 버튼을 조회 조건 줄이 아니라 머리말 오른쪽에 두는 근거다.

- Page header (Atlassian Design System) — https://atlassian.design/components/page-header
- Page header 가이드 문의 (Atlassian Community) — https://community.developer.atlassian.com/t/seeking-clarification-for-design-guidelines-for-page-headers/26204

## 4. 간격과 그리드

KRDS는 모든 간격을 8포인트 그리드로 정한다.
큰 화면은 12~16 칼럼, 스크린 마진은 24px 이상, 칼럼 사이 간격은 24px를 최적값으로 둔다.

칸 사이 12px, 줄 사이 16px, 화면 안쪽 여백 24px로 맞춘다. 모두 4의 배수이고 8포인트 체계 안에 든다.

- 레이아웃 (KRDS) — https://www.krds.go.kr/html/site/style/style_05.html

## 5. 목록 화면의 골격

Ant Design은 목록 페이지를 "위에서 아래로 쌓되 자료를 거르는 모듈을 맨 위에 둔다"로 정의한다.
Carbon은 표 위 도구 영역에 표시 설정을 두고 페이지네이션은 표 아래에 둔다.

두 규격을 합치면 골격은 이렇다.

```text
머리말        제목과 설명. 오른쪽에 주요 동작(등록은 강조, 내려받기는 보조)
조회 조건 카드  조건 세 개씩. 기간 버튼은 날짜 칸 오른쪽
             마지막 줄 오른쪽 끝에 [초기화] [조회]
             세그먼트와 토글은 조건 아래
요약 지표      셋에서 넷
표 위 도구     왼쪽에 표시 개수와 열 고르기, 오른쪽에 조회 건수
표            텍스트는 왼쪽, 숫자는 오른쪽, 날짜는 왼쪽. 머리도 값과 같은 쪽
페이지네이션    왼쪽에 한 쪽에 몇 건, 오른쪽에 쪽 이동
안내          표 아래. 조작 설명은 두지 않는다
```

조회 조건을 카드로 묶는 이유는 어디까지가 조건이고 어디부터 결과인지 눈으로 끊기 위해서다.
카드가 없으면 조건과 표가 한 덩어리로 보인다.

- 목록 페이지 (Ant Design) — https://ant-design.antgroup.com/docs/spec/research-list
- 표 열 정렬 (Pencil & Paper) — https://www.pencilandpaper.io/articles/ux-pattern-analysis-enterprise-data-tables

## 6. 상태 색과 표 밀도

### 상태 색

Carbon은 상태 색의 뜻을 정해 둔다. 빨강은 오류와 위험, 주황은 심각한 경고, 노랑은 보통 경고,
초록은 정상, 파랑은 진행과 안내, 회색은 초안이나 시작 전, 보라는 예외다.

Ant Design은 태그에 성공, 진행, 오류, 경고, 기본 다섯 가지를 미리 둔다.

KRDS는 시스템 색상을 주의·경고·성공을 알리는 데 쓰되
**색만으로 알리지 말고 아이콘이나 글자를 함께 쓰라고** 정한다.

- Status indicators (Carbon) — https://carbondesignsystem.com/patterns/status-indicator-pattern/
- Tag (Ant Design) — https://ant.design/components/tag/
- 색상 (KRDS) — https://www.krds.go.kr/html/site/style/style_02.html

### 표 밀도와 줄무늬

행 높이는 보통 48~56px, 조밀하게 볼 때 40~44px를 쓴다. 기본은 읽기 쉬운 쪽에 둔다.
열이 많은 표는 줄무늬나 행 강조로 눈이 줄을 놓치지 않게 한다.
표가 한 화면을 넘기면 열 머리를 고정한다.

- Data table design (Pencil & Paper) — https://www.pencilandpaper.io/articles/ux-pattern-analysis-enterprise-data-tables
- Table design UX (Eleken) — https://www.eleken.co/blog-posts/table-design-ux

### 모달

KRDS 모달은 오버레이, 헤더, 닫기 버튼, 본문, 푸터로 이루어진다.
푸터에 취소와 확인을 두고, 닫기 버튼은 마크업의 마지막에 두어 키보드로 내용을 다 지난 뒤 닫게 한다.
키보드 초점은 모달 안에서만 돌고, 닫으면 열었던 버튼으로 돌아간다.
데스크톱 웹은 주 동작을 오른쪽에 둔다.

- 모달 (KRDS) — https://www.krds.go.kr/html/site/component/component_04_05.html

### 조회 조건 접기

Ant Design Pro의 QueryFilter는 조건이 한 줄을 넘으면 접어 두고 펼치기 버튼을 검색 버튼 옆에 둔다.
Ant Design의 고급 검색 패턴도 기본은 접어 두고 필요할 때 펼치는 쪽이다.

접을 때 문제는 무엇을 걸어 두었는지 보이지 않는 것이다.
그래서 적용한 조건은 칩으로 늘 보여 주고, 조건을 걸어 둔 채로 돌아오면 접지 않는다.
데스크톱에서 조건이 대여섯 개 이하면 접지 않고 그대로 두어도 된다.

- Query/LightFilter (ProComponents) — https://procomponents.ant.design/components/query-filter/
- Filter UX patterns (Pencil & Paper) — https://www.pencilandpaper.io/articles/ux-pattern-analysis-enterprise-filtering
- Filter UI and UX (UXPin) — https://www.uxpin.com/studio/blog/filter-ui-and-ux/
