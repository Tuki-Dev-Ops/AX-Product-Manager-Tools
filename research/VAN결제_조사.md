# VAN 결제 망취소와 무서명 기준 조사

조사일 2026-09-04. 법령 원문은 국가법령정보센터에서 전문을 내려받아 검증했다.

## 1. 망취소

### 법령 용어가 아니다

여신전문금융업법, 시행령, 여신전문금융업감독규정, 전자금융감독규정 전문을 검색한 결과 망취소와 승인취소 문자열이 0건이다. VAN사와 결제대행사의 기술 규격상 용어다.

따라서 발동 조건과 재시도 정책은 연동 대상 VAN사 규격서로 확정해야 한다.

### 정의

KICC는 상점이 승인 요청을 보냈으나 네트워크 시간 초과 등으로 성공과 실패 응답을 받지 못한 상태일 때, 중복 결제를 막기 위해 해당 거래를 무조건 취소시키는 기능으로 정의한다.

나이스페이먼츠는 인증 응답 후 승인 요청 시 응답 데이터를 정상적으로 수신하지 못했거나 내부 서버 문제로 응답을 처리하지 못한 경우로 정의한다.

- https://docs.kicc.co.kr/docs/van-payment/simple/net-cancel
- https://developers.nicepay.co.kr/docs/pg/auth/net-cancel/

### 발동 조건은 셋이다

| 조건 | 내용 |
| --- | --- |
| 읽기 시간 초과 | 승인 요청 후 설정한 시간 안에 응답이 오지 않은 경우 |
| 연결 오류 | 승인 요청 중 연결이 끊기거나 네트워크 오류가 발생한 경우 |
| 응답 해석 실패 | 응답은 받았으나 형식이 깨져 성공 여부를 판단할 수 없는 경우 |

프린터 오류나 전표 출력 실패를 망취소 조건으로 규정한 근거는 확인되지 않았다.

### 일반취소와의 차이

일반취소는 원거래 승인 시 발급된 거래일련번호로 취소를 요청한다.

망취소는 기존 승인 요청 데이터를 그대로 다시 보낸다. 승인 결과를 받지 못한 상태이므로 승인번호를 취소 키로 쓸 수 없다.

식별에 쓰는 값은 단말기 번호, 가맹점 거래일련번호, 금액, 거래일시다.

### 망취소가 실패하면

스마트로는 단말기 오류로 취소가 되지 않으면 관리 대리점에 문의해 전산으로 확인 후 별도 처리한다고 안내한다. 이 경우 전표는 출력되지 않는다.

수기취소와 익일 대사 절차를 규정한 공개 문서는 확인하지 못했다. 개별 VAN사 가맹점 규약을 확인해야 한다.

### 미확인

- 망취소 전문의 재시도 횟수와 시간 제한. 세 결제대행사 공개 문서 모두 기재하지 않았다
- VAN사 단말기 연동규격서. 비공개다

## 2. 무서명 5만원 기준

### 근거는 감독규정이다

카드사 자율 정책이 아니다. 여신전문금융업감독규정 제24조의6 제2항이 근거다.

법령 체계는 넷으로 이어진다.

| 단계 | 조문 | 내용 |
| --- | --- | --- |
| 의무 | 여신전문금융업법 제19조 제2항 | 가맹점은 거래할 때마다 본인이 정당하게 사용하는지 확인해야 한다 |
| 위임 | 같은 법 제24조 제7호 | 금융위원회가 가맹점 관리에 관한 기준을 정할 수 있다 |
| 방법 | 감독규정 제24조의6 제1항 | 서명 대조, 비밀번호 입력, 생체정보 확인 등의 방법으로 본인확인을 한다 |
| 면제 | 감독규정 제24조의6 제2항 | 거래금액이 5만원 이하이고 카드사가 부정사용 책임을 부담하기로 가맹점에 통지한 경우 본인확인을 하지 않게 할 수 있다 |

법과 시행령에는 5만원 기준이 없다. 시행령 전문 검색 결과 관련 조문이 0건이다.

면제 주체는 카드사다. 감독규정이 카드사에게 면제 권한을 주고, 카드사가 가맹점에 통지하면 가맹점의 본인확인 의무가 면제된다.

- https://www.law.go.kr/행정규칙/여신전문금융업감독규정

### 변경 이력

감독규정 연혁 전 버전을 대조한 결과 문구가 동일하다.

| 시행일 | 기준 |
| --- | --- |
| 2023-08-30 | 5만원 이하 |
| 2024-05-21 | 5만원 이하 |
| 2024-06-26 | 5만원 이하 |
| 2025-02-14 | 5만원 이하 |
| 2026-01-02 | 5만원 이하 |
| 2026-05-06 현행 | 5만원 이하 |

2007년 7월 26일 신설 당시에는 가맹점과 별도 계약을 체결한 경우였다. 2016년 1월 28일 개정으로 카드사가 통지한 경우로 완화되었다. 금액 기준은 그대로다.

2024년부터 2026년 사이 개정이 없다.

### 미확인

체크카드와 직불카드에 같은 기준이 적용되는지는 조문상 확인되지 않는다. 감독규정 제24조의6 제2항은 신용카드를 대상으로 한다.

## 3. 무서명거래의 부정사용 책임

책임은 카드사가 진다. 이것이 면제의 성립 요건이다.

감독규정은 카드사가 부정사용 책임을 부담하기로 가맹점에 통지한 경우에만 본인확인 면제를 허용한다. 통지가 없으면 무서명거래가 성립하지 않는다.

손실 분담의 일반 원칙은 여신전문금융업법 제17조에 있다. 분실, 도난, 위조, 변조, 정보 유출, 명의 도용 거래의 손실을 가맹점이 부담하게 할 수 없다.

가맹점에 손실을 전가하려면 세 요건이 모두 필요하다.

1. 서면 또는 전자문서 계약
2. 계약서에 적힌 중대한 과실 사유
3. 카드사의 증명

가맹점의 중대한 과실 범위를 정한 시행령 조문은 없다. 개별 가맹점 계약서에 적힌 사항으로 정해진다.

- https://www.law.go.kr/법령/여신전문금융업법
