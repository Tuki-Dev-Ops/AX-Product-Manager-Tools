# 표시 정보 책임 귀속 조사

조사일 2026-09-08. 대상은 IS-036(표시 정보 검수 폐지에 따른 책임 명시)이다.
본사 검수를 없앤 뒤 알레르기와 원산지 표시 위반의 과태료가 누구에게 부과되는지, 플랫폼에 남는 의무가 있는지 확인했다.

---

## 1. 원산지 표시

### 표시 의무자

「농수산물의 원산지 표시 등에 관한 법률」 제5조제1항은 표시 의무자를 다음과 같이 정한다.

> 수입하는 자, 생산·가공하여 출하하거나 판매하는 자 또는 판매할 목적으로 보관·진열하는 자

음식점의 경우 조리·판매하는 영업자가 표시 의무자다. 가맹본부나 주문 플랫폼은 여기에 들어가지 않는다.

### 제재

| 위반 | 제재 | 근거 |
| --- | --- | --- |
| 원산지 미표시 | 1천만원 이하 과태료 | 제18조제1항제1호 |
| 표시방법 위반 | 1천만원 이하 과태료 | 제18조제1항제2호 |
| 거짓 표시 | 7년 이하 징역 또는 1억원 이하 벌금 | 제14조 |
| 시정명령 불이행 | 1년 이하 징역 또는 1천만원 이하 벌금 | 제9조, 제16조 |

### 중개자 의무

현행법(법률 제18525호, 2022-01-01 시행)에는 통신판매중개업자에 대한 원산지 관련 의무 조항이 없다.
제6조제5항의 방치 금지는 방송채널사용사업자(홈쇼핑)에만 적용된다.

다만 통신판매중개업자에게 방치 금지 의무를 부과하고 위반 시 1천만원 이하 과태료를 매기는 개정안이 발의된 상태다.
미표시 과태료 상한을 1천만원에서 1천500만원으로 올리는 내용도 함께 들어 있다. 시행 여부는 확정되지 않았다.

## 2. 알레르기 유발 식품 표시

### 대상 판정과 의무자

「어린이 식생활안전관리 특별법」 제11조의2에 따라 어린이 기호식품을 조리·판매하는 식품접객업소 중
가맹사업의 직영점과 가맹점을 합한 점포 수가 50개 이상인 경우가 대상이다.

대상 판정은 브랜드 규모로 하지만, 표시 의무는 각 가맹점 영업자(식품접객영업자)에게 있다.
가맹본부가 대신 표시하는 구조가 아니다.

### 표시 대상 품목

조리·판매 식품에 적용되는 목록은 「어린이 기호식품 등의 알레르기 유발 식품 표시기준 및 방법」(식약처 고시)에 있다.

> 알류(가금류), 우유, 메밀, 땅콩, 대두, 밀, 고등어, 게, 새우, 돼지고기, 복숭아, 토마토,
> 아황산류, 호두, 닭고기, 쇠고기, 오징어, 조개류(굴·전복·홍합 포함)

18종이다. 조개류는 굴·전복·홍합을 포함해 한 항목으로 센다.

「식품 등의 표시·광고에 관한 법률」 시행규칙 별표 2의 19종은 가공식품 기준이며 잣이 추가로 들어간다.
음식점의 조리·판매 식품에는 적용되지 않는다. 두 목록을 섞어 쓰면 화면 항목과 법정 항목이 어긋난다.

## 3. 플랫폼에 남는 의무

식품 표시 법령에는 없지만 전자상거래 법령에는 있다.

| 조문 | 내용 |
| --- | --- |
| 전자상거래법 제20조제1항 | 통신판매중개자는 자신이 당사자가 아니라는 사실을 미리 고지해야 한다 |
| 전자상거래법 제20조제2항 | 중개의뢰자의 정보를 소비자에게 제공하거나 열람할 방법을 제공해야 한다 |
| 전자상거래법 제20조의2 | 정보를 제공하지 않았거나 제공한 정보가 사실과 달라 소비자에게 재산상 손해가 생기면 중개의뢰자와 연대해 배상한다 |

행정 제재(과태료)는 매장에 부과되지만, 소비자에 대한 민사 책임은 플랫폼에 미칠 수 있다.
표시 정보를 매장이 등록한 그대로 전달하고, 누가 등록했는지와 언제 등록했는지를 남겨야 한다.

## 4. 본 서비스에 적용할 판단

| 항목 | 적용 |
| --- | --- |
| 과태료 귀속 | 매장이 부담한다. 가맹 계약서에 표시 의무와 과태료 부담 주체를 매장으로 명시한다 |
| 플랫폼 고지 | 주문 화면에 표시 정보가 매장이 등록한 내용임을 고지한다. 등록 매장명을 함께 표시한다 |
| 누락 차단 | 필수 표시 항목이 비어 있으면 판매 불가로 둔다. 이미 적용되어 있다 |
| 안내 이력 | 매장 등록 시 표시 의무를 1회 안내하고 안내 시각과 대상 계정을 남긴다 |
| 정확성 확인 | 하지 않는다. 값이 사실인지 확인할 방법이 없고, 확인한 것처럼 기록하면 책임 소재가 흐려진다 |
| 추적 | 원산지표시법 개정안이 시행되면 중개자 방치 금지 의무가 생긴다. 시행 시 매장 표시 상태 점검 기능을 검토한다 |

누락 차단과 안내 이력은 개정안이 시행되더라도 '방치하지 않았다'는 근거가 된다. 지금 구조를 바꾸지 않아도 된다.
